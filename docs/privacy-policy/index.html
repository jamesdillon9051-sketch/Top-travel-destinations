Privacy Policy

The short version: this site doesn't have accounts, doesn't use cookies, doesn't run analytics, and doesn't load anything from a third-party server. The long version is below. Last updated September 2026.

Data collection

What this site collects: nothing, directly

Travel Vault has no user accounts, no sign-up forms, no comment sections and no newsletter. There is nothing to fill in and nothing personal to submit, so nothing personal is stored by the site itself.

The site does not run any analytics or advertising scripts, does not set any cookies of its own, and does not use browser storage to track you across visits. Every stylesheet, script, font and image on this site is served from this same domain — none of it is pulled from Google Fonts, an ad network, a tracking pixel or any other third-party server. If you check your browser's network tab, that is verifiably true rather than a claim you have to take on faith.

Hosting

Hosting and server logs

This site is hosted on GitHub Pages. Like effectively any web host, GitHub's servers process standard technical information to deliver each page — things like IP address, browser type and the page requested — the way any web server does. That happens at the hosting level, is standard for any website on the internet, and is governed by GitHub's own privacy statement, not by anything this site configures or controls.

Leaving this site

External links

Pages link out to two kinds of external site: Wikimedia Commons, where every photograph on this site is sourced and credited, and GitHub, where the source code lives. Once you click through to either, you're on their site under their privacy policy — this policy only covers Travel Vault itself.

Children's privacy

Children's privacy

This site is general-audience travel content, not directed at children, and — per the section above — it doesn't knowingly collect personal information from anyone, child or adult, because it doesn't collect personal information at all.

Updates

Changes to this policy

If what this site does ever changes in a way that affects your privacy — for example, if analytics were added in future — this page would be updated to say so plainly, with the "last updated" date above changed to match. There is no mailing list to notify, because there is no mailing list.

Questions

Contact

Questions about this policy are welcome — the most direct way to reach me is to open an issue on GitHub.
